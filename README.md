# 8002 Pro — Android releases

Official public APK download and update channel for package `com.salmanbashir.cleanup8002`.

A new candidate is undergoing Android 14/16 verification. An APK will be published here only after its executable release gates pass. Beta releases are not Stable.

## Access

The app has a 3-day full trial from the original Android install date. A signed Pro activation key is required afterwards for new VPN, Private Browser, App Locker setup, firewall and other premium operations. Existing protection is not silently removed at expiry; PIN/fingerprint access to existing data, recovery, Disconnect and updates remain available.

Updates appear in Settings → Updates & reinstall. Enable beta builds explicitly to see prereleases. Install over the existing app to preserve data. Existing private-updater builds need a one-time manual APK update.

Full VPN needs an authorized remote WireGuard gateway; no free US/UK server or credentials are bundled. DNS-only protection does not change the public IP. Real-device ColorOS and live gateway acceptance remain required before Stable approval.

Source code, signing history and owner licence-signing tools are not distributed in this repository. Offline licensing cannot guarantee prevention of modified APKs, trial resets or misuse. Check the APK SHA-256 and signing metadata attached to each release.
